# ComicCraft - Frontend Only

## Features
- Demo login with LocalStorage
- Template-based demo story generation
- Comic panel layout
- Save and delete comics with LocalStorage
- PDF export using jsPDF CDN
- Responsive design

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. For best results, use VS Code Live Server extension.
4. Enter a name in Demo Login.
5. Enter a story idea.
6. Select genre and panel count.
7. Click Generate Demo Story.
8. Save the comic or export it as PDF.

## Important
This is a frontend-only academic prototype.
It does not use a backend, real database, or real Gemini API.
